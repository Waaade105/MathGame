Math Game

A simple console-based Math Game built with C#.

This project is part of The C# Academy learning path and is intended to reinforce fundamental C# concepts by building a small application independently.

Overview

The game asks the player a series of math questions and awards 1 point for each correct answer.

The player can choose which type of operation to practice:

Addition

Subtraction

Multiplication

Division

Each game contains at least 5 questions.

Requirements

Ask the player for the result of a math question, for example:

9 x 9 = ?

Collect the user's answer.

Add 1 point for each correct answer.

Each game must contain at least 5 questions.

Division questions must result in integers only.

For division:

The dividend must be between 0 and 100.

Questions such as 7 / 2 should not be presented because the result is not an integer.

Display a menu that allows the user to choose a math operation.

Store previous game results in a List.

Include a menu option that allows the user to view the history of previous games.

A database is not required.

Game history only needs to exist while the application is running. Once the program is closed, the history can be deleted.
